## How to use these prompts

1. Open a model or topic page and find a clip whose look you want.
2. Click the card to copy the prompt — the copy pulls the **complete text**, not the truncated preview.
3. Paste it into the model's own app or API (each entry links to the source post so you can check the exact workflow).
4. Swap the subject, setting or camera language to make it yours; the featured guides above explain the prompt patterns each model responds to.

## About the collection

- Prompts are curated from public posts by the AI video community. **Credit belongs to the original authors** — every entry links back to its source.
- Entries are reviewed by hand: titles, tags and model attribution are written per item, and prompts posted in reply threads are recovered into the full text.
- The site runs on Next.js 15 + Cloudflare Workers (OpenNext) with D1 and R2; see [`AGENTS.md`](AGENTS.md) and [`docs/`](docs/) for architecture and operational notes.
